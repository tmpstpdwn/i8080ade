# Intel 8080 Assembler, Disassembler and Emulator in C.

## Status

- [x] Assembler
- [x] Disassembler
- [ ] Emulator

## Usage

```
Usage:
  i8080ade -a <input.asm> <output.bin>
  i8080ade -d <input.bin>
  i8080ade -h | --help

Options:
  -a    Assemble a source file
  -d    Disassemble a binary file
  -h    Display this help message
```
